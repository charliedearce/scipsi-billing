This is the task specification. [PROGRESS.md](PROGRESS.md) owns current status. [DELIVERY.md](DELIVERY.md) defines full acceptance and migration requirements. Dependencies listed here supplement the previous phase's exit gate.

Existing task IDs are retained; additions below remain PLANNED unless the progress ledger records otherwise. Approval settles stated product/workflow choices, not implementation evidence, rates or phase gates; this documentation revision adds no runtime behavior.
