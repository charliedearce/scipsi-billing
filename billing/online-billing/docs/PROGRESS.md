Status meanings:

- `PLANNED`: not started.
- `IN_PROGRESS`: work started, required evidence incomplete.
- `BLOCKED`: specific dependency unavailable; record attempted checks and work that can continue.
- `AUTOMATED_VERIFIED`: implementation checks pass; not automatic business/device acceptance.
- `PILOT_PENDING`: required human/database/device acceptance remains.
- `DEFERRED`: intentionally outside the current release scope; no acceptance is claimed, and the task must be re-opened before that capability is enabled.
- `ACCEPTED`: task criteria met with evidence and any required business/operational acceptance identified. For documentation-only tasks, record the review performed instead of fictitious tests.
