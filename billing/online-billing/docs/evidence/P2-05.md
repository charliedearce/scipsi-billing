## Scope decision

The user confirmed that physical printing is not required for the current online-billing release. P2-05 is therefore intentionally deferred, not failed and not silently accepted.

The current scope is digital document delivery:

- Admin Document Studio drafts are validated server-side.
- Issued invoices use immutable server-rendered PDF artifacts.
- Browser preview/download and artifact integrity remain in scope.
- Digital print-attempt history remains auditable, but a successful browser print dialog is not treated as proof of device output.

Physical printer model, paper stock, tray, margins, scaling, operator flow and signed sample acceptance must be collected if a later release enables device printing. Re-open P2-05 before that release and attach the accepted printer/paper evidence to this task.
