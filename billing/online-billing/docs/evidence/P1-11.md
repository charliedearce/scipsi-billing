# P1-11 Evidence — PWA Shell and Safe Update/Offline Boundary

Date: 2026-09-19. Status: AUTOMATED_VERIFIED (pending build verification below).

## Task summary

Implemented Progressive Web App (PWA) readiness for the Vue frontend per the approved W33 contract (Decision W33, [`PWA_READINESS.md`](../discovery/PWA_READINESS.md)). Deliverables:

- Installable web app manifest with correct SCIPSI branding, icons, display mode and start URL.
- Versioned PNG icons (192×192, 512×512, maskable 512×512) generated from SVG source via `@resvg/resvg-js`.
- `vite-plugin-pwa@0.21.1` (Workbox `generateSW`) integrated into the Vite build pipeline.
- **Strict W33 cache classification** — only hashed shell assets (JS, CSS, fonts, icons) are precached; all API/auth/financial/upload routes are `NetworkOnly`.
- `registerType: 'prompt'` — the service worker never silently `skipWaiting()`; updates are user-triggered.
- `OfflineIndicator.vue` — global strip shown when `navigator.onLine === false`, using VueUse `useOnline`.
- `PwaUpdateBanner.vue` — non-alarming toast shown when a waiting SW update is available; user must click "Reload now".
- `usePwaUpdate` composable wrapping `virtual:pwa-register/vue`.
- `pwa-session.ts` utility — `clearPwaRecoveryState()` + `purgePwaCaches()` called on `logOut()`.
- Apple PWA meta tags added to `index.html`; SW disabled in dev mode.
