## Implementation and evidence

- Legacy source paths/symbols and confidence: Legacy billing system had no digital customer upload or document verification capability; documents were physical paper handled manually at cashier windows. Replaced by an isolated private storage layer with versioning, security scanning, and role-segregated access.
- Changed paths and resulting behavior:
  - Configured `local_private` filesystem disk in `config/filesystems.php` mapped strictly to `storage/app/private/` with private visibility, forbidding public web exposure.
  - Added migration `2026_09_19_100007_create_document_requirements_and_private_files_tables.php` establishing:
    - `document_types`: Named document catalog categorized into 4 purposes: `BILLING_SUPPORT`, `WITHHOLDING_CERTIFICATE`, `EXEMPTION_EVIDENCE`, `PAYMENT_PROOF`, with mime type, size, and file count constraints.
    - `document_requirements`: Versioned service/location requirement rules with optimistic locking (`lock_version`).
    - `private_files`: Aggregate root for customer and billing files.
    - `private_file_versions`: Append-only immutable file versions with monotonic numbering, SHA-256 checksums, and scan statuses.
  - Implemented `PrivateStorageService`:
    - Validates file MIME types, extensions, and size limits against configured `DocumentType`.
    - Prohibits executable/malicious extensions (`.exe`, `.bat`, `.php`, `.sh`, `.ps1`).
    - Computes SHA-256 digest on storage and persists files in hashed directory hierarchy.
    - Implemented heuristic/antivirus scanning with quarantine state machine (`PENDING`, `CLEAN`, `QUARANTINED`).
    - Enforces that quarantined files cannot be streamed or downloaded by normal users.
    - Supports versioned file replacement with explicit reason logging while preserving prior versions for legal hold.
    - Implemented streaming downloads verifying cross-organization isolation, customer ownership, and staff reviewer authorization (`files:review`).
  - Seeded 6 new permissions (`documents:read`, `documents:manage`, `files:upload`, `files:view`, `files:review`, `files:quarantine`) and 5 default document types (`BILL_OF_LADING`, `CARGO_MANIFEST`, `BIR_2307`, `TAX_EXEMPTION_CERT`, `BANK_DEPOSIT_SLIP`).
  - Added API endpoints for document types, requirements, uploads, replacement, quarantine, and streaming downloads.
  - Created TypeScript API client `apps/web/src/api/documentRequirements.ts`.
